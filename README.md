## 📌 Project Overview
This project simulates real-world analytics workflows of an e-commerce platform. Using relational database architecture across customer demographics, product catalogs, and transactional order histories, this analysis delivers strategic, data-driven insights across four core business pillars:
- **Customer Segmentation & Engagement**: Identifying geographic hubs and cohort behaviors.
- **Product Portfolio Performance**: Finding premium single-unit items and cross-category market reach.
- **Sales Trends & Unit Economics**: Evaluating Month-over-Month (MoM) revenue changes and Average Order Value (AOV).
- **Inventory & Demand Planning**: Pinpointing fast-moving SKUs, low-engagement inventory, and peak demand cycles.
